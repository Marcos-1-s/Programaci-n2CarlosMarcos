# Práctica — Del enunciado al programa

Programa en Python orientado a resolver el cálculo automatizado de descuentos comerciales para una tienda.

## Reglas de Negocio
- Compras inferiores a 100 €: Sin descuento (0%).
- Compras desde 100 € hasta menos de 300 €: Descuento del 10%.
- Compras a partir de 300 €: Descuento del 15%.

## Estructura del Repositorio
- `main.py`: Código fuente del programa con tipado estático básico y docstrings.
- `README.md`: Documentación detallada del proyecto (análisis, diseño, codificación y pruebas).

## Requisitos de Ejecución
- Python 3.8 o superior instalado.
- Ejecutar el programa mediante el comando:
  ```bash
  python main.py
